# PopGuard パラメータシートテスト手順

## テスト対象モジュール

`docs\parameter-sheet.xlsm`

■ このブックは `tools\parameter-sheet\make-parameter-sheet.ps1` が生成する。
  出力処理のマクロは `tools\parameter-sheet\ExportConfig.bas` である。
  不具合を見つけた場合は、ブックではなくこれらを修正してブックを作り直す。

## 準備

* Microsoft Excel をインストールする
* ブックを生成する（未生成の場合）。リポジトリのルートの PowerShell で実行する
  ```
  pwsh -File tools\parameter-sheet\make-parameter-sheet.ps1
  ```
  ■ 生成には Excel と、[ファイル] → [オプション] → [トラスト センター] → [トラスト センターの設定]
    → [マクロの設定] の「VBA プロジェクト オブジェクト モデルへのアクセスを信頼する」が必要。
* `docs\parameter-sheet.xlsm` を作業用のフォルダー（例：`C:\PopGuardTest\parameter-sheet\`）にコピーする
  * 以下のテストはすべてコピーしたブックで行う
  * ※出力先がブックと同じ場所になるため、リポジトリ内に出力ファイルを残さないようにする
* コピーしたブックを Excel で開き、「コンテンツの有効化」を押してマクロを有効にする
  * ボタンが反応しない場合は、エクスプローラーでブックのプロパティを開き、
    「セキュリティ: 許可する」にチェックを入れてから開き直す

■ 以下、`{ブックのフォルダー}` はコピーしたブックがあるフォルダーに読み替える。

■ テストの途中でブックを保存しないこと。各テストは、コピーしたての状態から始める。
  続けて行う場合は、保存せずに閉じて、もう一度コピーし直す。

## 自動テスト

* リポジトリのルートの PowerShell で以下を実行する
  ```
  pwsh -File tools\parameter-sheet\test-parameter-sheet.ps1
  ```
  * [ ] 最後に「すべて成功しました。」と表示されること

■ 自動テストは、出力する JSON の内容と入力チェックを、Excel の画面を使わずに確認する。
  以下の手順では、ボタン・ダイアログ・入力規則・出力ファイルなど、画面操作を伴う部分を確認する。

# テスト

## 初期値

* [ ] 「全般 (General)」シートの初期値が以下の通りであること
  * ```
    パラメータ	値	内部パラメータ名	備考
    フォーカス セッション中は自動で抑止する	有効	AutoSuppressDuringFocus	…
    マイク使用中は自動で抑止する	無効	AutoSuppressDuringMicrophone	既定は無効
    表示言語	自動	Language	「自動」は OS の表示言語に従います (日本語以外は英語)
    ```
* [ ] 「抑止ルール (Rules)」シートの初期値が、ルールの入力行が**空**であること
  * [ ] 「有効」「隠し方」「TOPMOSTのみ」「抑止しない」の各列にプルダウンが設定されていること
* [ ] 「抑止時間 (Durations)」シートの初期値が、以下の 5 件であること
  * ```
    ラベル (日本語)	ラベル (英語)	分
    30分	30 min	30
    1時間	1 hour	60
    2時間	2 hours	120
    一日	1 day	1440
    無制限	Unlimited	0
    ```

## 入力規則

* 「全般 (General)」シート：
  * [ ] 「フォーカス セッション中は自動で抑止する」の値が **有効 / 無効** のプルダウンであること
  * [ ] 「マイク使用中は自動で抑止する」の値が **有効 / 無効** のプルダウンであること
  * [ ] 「表示言語」の値が **自動 / 日本語 / 英語** のプルダウンであること
* 「抑止ルール (Rules)」シート：
  * [ ] 「有効」が **有効 / 無効**、「隠し方」が **背面へ送る / 最小化 / 非表示**、
        「TOPMOSTのみ」が **有効 / 無効**、「抑止しない」が **有効 / 無効** のプルダウンであること
* 「抑止時間 (Durations)」シート：
  * 「分」の列に、負の数（例：`-1`）を手入力して Enter を押す
    * [ ] 「0 以上の整数を入力してください。」というエラーが表示され、入力できないこと

## 初期値のエクスポート

### 準備

* コピーしたてのブックを開く（値は変更しない）

### テスト

* 「エクスポート」シートのボタン「パラメータシートの内容を設定ファイルとして出力する」を押す
  * [ ] 出力先を知らせる確認ダイアログが表示されること
* [OK] を押す
  * [ ] 「出力しました。」というダイアログが表示されること
* `{ブックのフォルダー}\PopGuard_export\<日時>\PopGuard.rules.json` を開く
  * [ ] 次の内容であること（`rules` は空、`durations` は既定の 5 件、`autoSuppressDuringFocus` は true、
        `language` は auto）
    ```json
    {
      "rules": [],
      "durations": [
        { "label": { "ja": "30分", "en": "30 min" }, "minutes": 30 },
        { "label": { "ja": "1時間", "en": "1 hour" }, "minutes": 60 },
        { "label": { "ja": "2時間", "en": "2 hours" }, "minutes": 120 },
        { "label": { "ja": "一日", "en": "1 day" }, "minutes": 1440 },
        { "label": { "ja": "無制限", "en": "Unlimited" }, "minutes": 0 }
      ],
      "autoSuppressDuringFocus": true,
      "language": "auto"
    }
    ```

## 出力の繰り返し

### 準備

* 初期値のエクスポートを行ったブックを、そのまま使う

### テスト

* もう一度エクスポートのボタンを押して出力する
  * [ ] 前回とは別の `<日時>` フォルダーに出力され、前回のファイルが上書きされないこと

## 値を指定してのエクスポート

### 準備

* コピーしたてのブックを開く

### テスト

* 「全般 (General)」シートで以下を変更する
  * 「フォーカス セッション中は自動で抑止する」を **無効** にする
  * 「表示言語」を **英語** にする
* 「抑止ルール (Rules)」シートの 1 行目に以下を入力する
  * 有効: **有効** / プロセス: `ToastTester` / タイトル: `保存先 C:\tmp\x "y"` /
    隠し方: **最小化** /（TOPMOSTのみは空欄のまま）
* 「抑止時間 (Durations)」シートの空行に以下を追加する
  * ラベル (日本語): `90分` / ラベル (英語): `90 min` / 分: `90`
* 「エクスポート」シートのボタンを押して出力する
* 出力された `PopGuard.rules.json` を開く
  * [ ] `autoSuppressDuringFocus` が `false` であること
  * [ ] `language` が `en` であること
  * [ ] `rules` が 1 件で、`process` が `ToastTester`、`hide` が `Minimize`、
        `topMostOnly` が `true`（空欄のため既定の true）であること
  * [ ] `title` が `保存先 C:\tmp\x "y"` であり、ファイル内では `\` が `\\`、`"` が `\"` に
        エスケープされていること（`保存先 C:\\tmp\\x \"y\"`）
  * [ ] `durations` が既定の 5 件に加えて `{ "label": { "ja": "90分", "en": "90 min" }, "minutes": 90 }` を含むこと

## 空欄の扱い

### 準備

* コピーしたてのブックを開く

### テスト

* 「抑止ルール (Rules)」シートの 2 行目以降は空欄のままにする
* 1 行目にプロセス `ToastTester` だけを入力する
* エクスポートする
  * [ ] 出力の `rules` が 1 件だけであること（空行は読み飛ばされる）

## 入力エラー

### 準備

* コピーしたてのブックを開く

### テスト

* 「抑止ルール (Rules)」シートの 1 行目で、プロセスを空欄のまま「タイトル」にだけ値を入れる
* エクスポートのボタンを押す
  * [ ] 「入力内容に問題があります。」のダイアログが表示され、プロセス名が無い旨が示されること
  * [ ] 出力が行われないこと
* プロセスに `ToastTester` を入れて修正する
* 「抑止時間 (Durations)」シートの空行に、「ラベル (日本語)」だけ入れて「分」を空欄にする
* エクスポートのボタンを押す
  * [ ] 「分」が空欄である旨のエラーが表示され、出力が行われないこと
  ■ ラベル（日本語／英語）はどちらも省略可能（両方空欄なら「分」から自動生成）。必須なのは「分」のみ。
