# PopGuard 連結テスト手順書

インストーラー・常駐アプリ（`PopGuard.exe`）・設定ファイル（`PopGuard.rules.json`）を組み合わせた状態で、
機能が意図どおり連動することを確認する。

単体テストで検証済みの判定ロジック（ルール一致、モーダル判定など）は対象としない。
本書は、**インストールから設定の読み込み、実際のウィンドウ抑止・復元までの経路が実際につながっていること**を対象とする。
検証用ツールとして **ToastTester** を使用する。

## 確認の記号

* `* [ ]` … 実施者がチェックする確認項目
* `■` … 補足・注意事項

## テスト環境

### 対象構成

1. PopGuard 常駐アプリ（`PopGuard.exe`、インストール済み）
2. 設定ファイル `PopGuard.rules.json`
3. 検証用ツール `ToastTester`（`ToastTester.exe`）

### 事前準備

* [ ] テスト用の `PopGuardSetup-<バージョン>.exe` を準備する（`SetupOutput\`）
* [ ] テスト対象のマシンに PopGuard がインストールされて**いない**こと
* [ ] `ToastTester` を用意する（`dotnet build ToastTester\ToastTester.csproj` の出力、または発行した `ToastTester.exe`）
* [ ] 代表設定ファイル（`docs/verify/testconfig/01_bottom.json` と `02_hide.json`）を手元に用意する
* （任意）フォーカス連動を確認する場合、テスト端末が **Windows 11 22H2（ビルド 22621）以降**であること
  ■ 22H2 未満の環境では、フォーカス連動の手順はスキップしてよい（他の手順は実施できる）。

### 設定変更の反映手順

各例で設定を変更する場合、以下の手順で反映させる。

* 設定ファイルを `PopGuard.exe` と同じフォルダー（既定 `C:\Program Files\PopGuard`）へ上書き保存する
* PopGuard を再起動する（トレイメニューの「終了」→ 再度 `PopGuard.exe` を起動、またはサインインし直す）

■ 設定は PopGuard の**起動時に一度だけ**読み込まれる。変更後は必ず再起動すること。

# インストールと常駐の確認

## インストール

1. `PopGuardSetup-<バージョン>.exe` を管理者権限で実行し、「スタートアップ」を有効にしたままインストールする：
  * [ ] `C:\Program Files\PopGuard` に `PopGuard.exe` が配置されること
  * [ ] タスクトレイに PopGuard のアイコン（灰色＝抑止していない）が表示されること
  * [ ] `HKLM\Software\Microsoft\Windows\CurrentVersion\Run` に `PopGuard` のエントリが登録されること

## 自動起動

1. サインインし直す：
  * [ ] PopGuard が自動的に起動し、タスクトレイに常駐すること

■ PopGuard は各ユーザーのセッション内・一般ユーザー権限のプロセスとして動作する。

# 代表的な設定例による確認

設定ファイルを入れ替えて、インストール〜設定読み込み〜抑止・復元までが一貫して動くことを確認する。
設定ファイルは `docs/verify/testconfig/` のものをそのまま配置する。

## 共通の手順

各例について、以下を行う。

1. 対象の設定ファイルを `PopGuard.exe` と同じフォルダーへ上書き配置する（配置後の名前は `PopGuard.rules.json`）
2. PopGuard を再起動する
3. `ToastTester` を起動する
4. 各例の確認項目を実施する

■ ToastTester の「自前トーストを表示」で出るポップアップは、約 5 秒で自動的に閉じる。
  抑止・復元の瞬間を目視しづらい場合は、ログ（`%LOCALAPPDATA%\PopGuard\PopGuard.log`）の
  `guard demote:` / `guard restore:` でも確認できる。

## 例 1：背面へ送る（`01_bottom.json`）

自前トーストを「背面へ送る（`Bottom`）」で抑止する。**タイトル指定で一致**、**手動抑止のみ**、**日本語表示**。

1. トレイアイコンを右クリックしてメニューを開く：
  * [ ] メニューと状態表示が**日本語**であること（`language = ja`）
  * [ ] 「ウィンドウを抑止する」の候補が **1分 / 30分 / 無制限** であること（`durations`）
2. 抑止オフ（アイコン灰）のまま、ToastTester で「**自前トーストを表示**」する：
  * [ ] 右下にトーストが表示され、**裏へ送られない**こと（抑止オフのため）
3. トレイメニュー →「ウィンドウを抑止する」→「**無制限**」を選ぶ：
  * [ ] アイコンが**緑**になり、状態が「抑止中（無制限）」になること
4. ToastTester で「**自前トーストを表示**」する：
  * [ ] トーストが**ほぼ即座に背面へ送られ**、最前面に残らないこと
  * [ ] ログに `guard demote: process=ToastTester title=ToastTester Toast method=Bottom` が出ること
5. ToastTester で「**モーダルウィンドウを表示**」する：
  * [ ] モーダルは**抑止されず前面のまま**であること（モーダル回避）。確認後「閉じる」で閉じる
  * [ ] ログに `guard skip: … (likely dialog: …)` が出ること
6. ToastTester で「**OS トースト（本物）を表示**」する：
  * [ ] OS トーストは**抑止されない**こと（PopGuard の対象外）
7. トレイメニュー →「**抑止を停止**」を選ぶ：
  * [ ] アイコンが**灰**になり、状態が「抑止していません」になること
  * [ ] 以降の自前トーストは裏へ送られないこと
8. （任意）「ウィンドウを抑止する」→「**1分**」を選び、1 分待つ：
  * [ ] 1 分後に**自動的に抑止が解除**され、状態が灰に戻ること（ログに `guard: suppression ended (time expired)`）

## 例 2：非表示＋フォーカス連動（`02_hide.json`）

自前トーストを「非表示（`Hide`）」で抑止する。**プロセス名のみで一致**、**フォーカス連動 ON**、**英語表示**。

1. トレイメニューを開く：
  * [ ] メニューと状態表示が**英語**であること（`language = en`）
2. 「ウィンドウを抑止する」→「無制限」で手動抑止し、ToastTester で「**自前トーストを表示**」する：
  * [ ] トーストが**即座に非表示**になること（画面から消える）
  * [ ] ログに `guard demote: process=ToastTester … method=Hide` が出ること
  ■ `Hide` は一時的な非表示。抑止停止・PopGuard 終了で復元される（ただしトーストは約 5 秒で自ら閉じるため、
    復元の目視が難しい場合はログの `guard restore:` で確認する）。
3. フォーカス連動（**Windows 11 22H2 以降のみ**）：
  1. 「抑止を停止」して抑止オフ（灰）にする
  2. Windows の**フォーカス セッションを開始**する：
    * [ ] 状態が「抑止中（フォーカス中）」になり、アイコンが緑になること
    * [ ] この状態で自前トーストを出すと非表示になること
  3. **フォーカス セッションを終了**する：
    * [ ] **自動的に抑止が解除**され、灰に戻ること
  ■ 手動の「応答不可（Do Not Disturb）」だけでは連動しない。連動対象はフォーカス セッション。
4. 復元の確認：
  * トレイメニュー →「**終了**」で PopGuard を終了する：
    * [ ] 非表示にされていたウィンドウが残っていれば元に戻ること（ログに `guard restore:`）

## ログの確認

* [ ] `%LOCALAPPDATA%\PopGuard\PopGuard.log` に、設定読み込み（`rules: …`）、抑止の開始・終了
  （`guard: suppression …`）、裏送り・復元（`guard demote:` / `guard restore:`）が記録されていること
* [ ] 例 2 で、フォーカス状態の変化（`focus-session: …`）が記録されていること（22H2 以降の場合）
* [ ] 例外（`fatal`）が記録されて**いない**こと

## 設定を戻す／後片付け

* [ ] 確認終了後、元の設定ファイルに戻す（または `PopGuard.rules.json` を削除する）
* [ ] PopGuard を再起動する
* [ ] ToastTester を終了する

# アンインストールの確認

1. PopGuard をアンインストールする：
  * [ ] `C:\Program Files\PopGuard` のファイルが削除されること
  * [ ] `HKLM\...\Run` の `PopGuard` エントリが削除されること
  * [ ] `HKLM\Software\PopGuard` が削除されること
  * [ ] トレイのアイコンが消えること（実行中だった場合は停止される）
