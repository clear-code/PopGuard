# PopGuard セットアップのWindows向けテスト手順

PopGuard のインストーラー（Inno Setup の exe）が、インストール・自動起動の登録・上書き・アンインストールを
正しく行うことを確認する。

## 準備

* テスト環境: Windows 10（1809 以降）または Windows 11（x64）
  * 管理者権限を持つユーザーで実施すること
* .NET SDK 9 以上をインストールする（発行に使用）
  * https://dotnet.microsoft.com/ja-jp/download
* Inno Setup 6 をインストールする（インストーラーのビルドに使用）
  * https://jrsoftware.org/isinfo.php

■ 以下、`{バージョン番号}` は `PopGuard.iss` の `AppVersion` の値（例：`1.0.0.0`）に読み替える。

## セットアップのビルドスクリプト検証

* リポジトリのルートで以下を実行する
  ```
  pwsh -File build.ps1
  ```
  * [ ] 「発行 (self-contained Release win-x64)」が実行され、続けて「インストーラーのビルド (Inno Setup)」が
        実行されること
  * [ ] `SetupOutput\PopGuardSetup-{バージョン番号}.exe` が作成されること
* `SetupOutput\PopGuardSetup-{バージョン番号}.exe` を右クリックし、[プロパティ] → [詳細] を開く
  * [ ] 「製品バージョン」が `{バージョン番号}` であること

■ 自己完結（self-contained）で発行しているため、インストール先には .NET ランタイムが同梱される。
  テスト端末に .NET ランタイムが入っていなくても動作することを、後述の起動確認で見る。

# exe セットアップ動作検証

## 新規インストール（スタートアップあり）

### 準備

* 既に PopGuard がインストールされている場合はアンインストールしておく
  * Windows の [設定] → [アプリ] → [インストールされているアプリ] から削除する

### テスト

* `SetupOutput\PopGuardSetup-{バージョン番号}.exe` をダブルクリックする
  * [ ] ユーザーアカウント制御のダイアログが表示されること
* [はい] を押す
  * [ ] セットアップが日本語で起動すること
  * [ ] [インストール先の指定] 画面で、既定が `C:\Program Files\PopGuard` であること
* そのまま [次へ] を押す
  * [ ] [追加タスクの選択] 画面に「スタートアップ:」の下に
        「Windows へのサインイン時に自動的に起動する」が表示され、**チェックが入っている**こと
* チェックを入れたまま進め、[インストール] を押す
  * [ ] インストールが完了すること
  * [ ] 完了画面に「PopGuard を起動する」のチェックがあること
* 「PopGuard を起動する」にチェックを入れて [完了] を押す
  * [ ] タスクトレイに PopGuard のアイコン（灰色＝抑止していない）が表示されること

### 配置の確認

* [ ] `C:\Program Files\PopGuard\PopGuard.exe` が存在すること
* [ ] 同フォルダーに `ja\PopGuard.resources.dll` など、発行物一式が配置されていること

### レジストリの確認

管理者権限の PowerShell で確認する。

```
Get-ItemProperty "HKLM:\Software\PopGuard"
Get-ItemProperty "HKLM:\Software\Microsoft\Windows\CurrentVersion\Run" -Name PopGuard
```

* [ ] `HKLM\Software\PopGuard` に `Path` / `Version` / `ConfigFile` が記録されていること
* [ ] `HKLM\...\Run` に `PopGuard` の値（`"C:\Program Files\PopGuard\PopGuard.exe"`）が登録されていること

### 自動起動の確認

* サインインし直す
  * [ ] PopGuard が自動的に起動し、タスクトレイに常駐すること

## 新規インストール（スタートアップなし）

### 準備

* PopGuard をアンインストールしておく

### テスト

* インストーラーを実行し、[追加タスクの選択] で
  「Windows へのサインイン時に自動的に起動する」の**チェックを外して**インストールする
  * [ ] インストールが完了すること
* レジストリを確認する
  ```
  Get-ItemProperty "HKLM:\Software\Microsoft\Windows\CurrentVersion\Run" -Name PopGuard -ErrorAction SilentlyContinue
  ```
  * [ ] `PopGuard` の値が**登録されていない**こと

## サイレントインストール

### 準備

* PopGuard をアンインストールしておく

### テスト

* 管理者権限のコマンドプロンプトで以下を実行する
  ```
  SetupOutput\PopGuardSetup-{バージョン番号}.exe /VERYSILENT
  ```
  * [ ] 画面の操作なしにインストールが完了すること
  * [ ] `C:\Program Files\PopGuard\PopGuard.exe` が配置されること
  * [ ] 既定（スタートアップあり）で `HKLM\...\Run` に `PopGuard` が登録されること

## 上書きインストール

### 準備

* PopGuard をインストール済みにする
* `C:\Program Files\PopGuard\PopGuard.rules.json` を作成しておく（任意の内容でよい）
* PopGuard を起動しておく（トレイに常駐させる）

### テスト

* 同じインストーラーをもう一度実行して上書きインストールする
  * [ ] 実行中の PopGuard が停止されたうえで上書きされること（エラーにならないこと）
  * [ ] インストール完了後、再び起動できること
* 設定ファイルを確認する
  * [ ] `PopGuard.rules.json` が上書きされず、インストール前の内容のまま残っていること
    ■ インストーラーは設定ファイルを `onlyifdoesntexist` で扱うため、既存の設定を保持する。

# アンインストール

### 準備

* PopGuard をインストール済みにする（スタートアップあり）

### テスト

* Windows の [設定] → [アプリ] → [インストールされているアプリ] から PopGuard を削除する
  （または `{app}` のアンインストーラーを実行する）
  * [ ] 実行中だった PopGuard が停止されること
  * [ ] `C:\Program Files\PopGuard` のファイルが削除されること
  * [ ] `HKLM\...\Run` の `PopGuard` の値が削除されること
  * [ ] `HKLM\Software\PopGuard` が削除されること
  * [ ] タスクトレイから PopGuard のアイコンが消えること

### 後片付け

* [ ] 残った `C:\Program Files\PopGuard` を手動で削除する（設定などが残っていた場合）
  ■ ログは `%LOCALAPPDATA%\PopGuard\` に残る。必要に応じて削除する。
