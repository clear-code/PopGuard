# PopGuardとは

PopGuardは、作業中に割り込んでくる最前面のポップアップウィンドウを、一時的に裏側へ送って
邪魔にならないようにする常駐アプリです。タスクトレイ（通知領域）に常駐し、必要なときだけ抑止を行います。

対象になるのは、システム管理者があらかじめ指定したアプリの、最前面（常に手前に表示される）ウィンドウです。
どのアプリを対象にするか、どのように抑止するか（裏へ送る／最小化する／非表示にする）は、
システム管理者の設定によって決まります。

PopGuardは、抑止を終了したときやアプリを終了したときに、裏へ送ったウィンドウを元の状態へ戻します。
ウィンドウを削除したり、閉じたりはしません。

■ PopGuardが抑止できるのは「アプリが独自に表示する最前面ウィンドウ」です。
Windows 標準の通知（画面右下に出るトースト通知）は抑止できません。
トースト通知を抑えたい場合は、Windows の「応答不可」や「フォーカス セッション」、アプリごとの通知設定をご利用ください。

\newpage

# タスクトレイのアイコンとメニュー

PopGuardはタスクトレイにアイコンを表示します。アイコンの色で現在の状態が分かります。

| アイコン | 状態 |
| --- | --- |
| 緑 | 抑止中（対象のウィンドウを裏へ送っています） |
| 灰 | 抑止していません |

アイコンを右クリックすると、次のメニューが表示されます。

| メニュー | 内容 |
| --- | --- |
| 状態: … | 現在の状態（「抑止していません」「抑止中（残り mm:ss）」など） |
| ウィンドウを抑止する | 抑止する時間を選びます（例: 30分 / 1時間 / 2時間 / 一日 / 無制限） |
| 抑止を停止 | 抑止を今すぐ終了します（抑止中のみ選べます） |
| 終了 | PopGuardを終了します |

■ 選べる時間の候補は、システム管理者の設定によって変わることがあります。

\newpage

# ウィンドウを抑止する

## 手動で抑止する

1. タスクトレイのPopGuardアイコンを右クリックします。
2. 「ウィンドウを抑止する」から、抑止したい時間（例: 1時間）を選びます。
3. アイコンが緑に変わり、以降は対象のウィンドウが裏へ送られます。

選んだ時間が過ぎると、自動的に抑止が終了します。途中でやめたいときは「抑止を停止」を選びます。
「無制限」を選んだ場合は、「抑止を停止」するか、PopGuardを終了するまで抑止が続きます。

## Windows のフォーカス セッションと連動する

システム管理者の設定で連動が有効になっている場合、**Windows 11 のフォーカス セッション中は自動的に抑止**されます。
フォーカス セッションを終了すると、抑止も自動的に終了します。

* このとき、状態は「抑止中（フォーカス中）」と表示されます。
* **手動の「応答不可（Do Not Disturb）」だけでは連動しません。** 連動するのはフォーカス セッションです。
* 手動で抑止を開始・停止した場合は、その操作が優先されます。

\newpage

# 抑止されたウィンドウの挙動

対象のウィンドウは、システム管理者の設定に応じて次のいずれかの方法で処理されます。

| 方法 | 挙動 |
| --- | --- |
| 背面へ送る | 最前面属性を外し、他のウィンドウの後ろへ移動します（既定） |
| 最小化 | ウィンドウを最小化します |
| 非表示 | ウィンドウを一時的に非表示にします |

いずれの場合も、**抑止を終了したとき、PopGuardを終了したときに、ウィンドウは元の状態へ戻ります**。

■ ウィンドウが出てから裏へ送られるまでに、ごく短い間だけ画面に見えることがあります。
PopGuardはウィンドウの出現を検知して即座に処理しますが、アプリによっては最前面になるのが
わずかに遅れるため、その間だけ見えることがあります。

\newpage

# 抑止されないもの

次のものはPopGuardの対象外です。

* **最前面ではないウィンドウ** … PopGuardは最前面（常に手前）のウィンドウだけを対象にします。
* **モーダルダイアログ** … 「OK／キャンセル」などで応答するまで操作をブロックするダイアログは、
  裏へ送ると操作できなくなるため、対象から除外されます。
* **Windows 標準の通知（トースト通知）** … アプリのウィンドウではなく Windows が描画するため、対象外です。
* **管理者権限で動作しているアプリのウィンドウ** … PopGuardは一般ユーザー権限で動作するため、
  より高い権限で動くアプリのウィンドウは操作できません。
* **ルールに一致しないウィンドウ** … システム管理者が指定した条件（アプリ名など）に合わないものは対象外です。

\newpage

# 設定について

PopGuardの設定は、**システム管理者が管理します。利用者が変更することはできません。**

設定は、PopGuardをインストールしたフォルダーにある設定ファイル `PopGuard.rules.json` に保存されています
（既定では `C:\Program Files\PopGuard\PopGuard.rules.json`）。このファイルは管理者権限で管理されています。

対象にするアプリや抑止の方法を変更したい場合、業務に必要なウィンドウが裏へ送られてしまう場合は、システム管理者へお問い合わせください。

## ログ

PopGuardの動作記録（ログ）は、次の場所に保存されます。

```
%APPDATA%\PopGuard\PopGuard.log
```

（通常は `C:\Users\<ユーザー名>\AppData\Roaming\PopGuard\PopGuard.log`）

ログには、抑止の開始・終了や、裏へ送った／戻したウィンドウの記録が残ります。
記録の内容についてはシステム管理者へお問い合わせください。

# FAQ（よくある質問）

## ポップアップが一瞬だけ見えました

PopGuardはウィンドウの出現を検知して即座に裏へ送りますが、アプリによっては表示のあとで
最前面になるため、その間だけ見えることがあります。異常ではありません。

## あるウィンドウが裏へ送られません

次のいずれかに当てはまる可能性があります。

* そのウィンドウが**最前面ではない**（PopGuardの対象は最前面ウィンドウのみ）。
* **モーダルダイアログ**である（安全のため対象外）。
* **管理者権限**で動くアプリのウィンドウである。
* システム管理者の**ルールに一致していない**。

詳しくはシステム管理者へお問い合わせください。

## 裏へ送られたウィンドウが戻ってきました

抑止の時間が終了したか、「抑止を停止」またはPopGuardの終了によって、ウィンドウが元に戻ったためです。
正常な動作です。

## トースト通知（画面右下の通知）が止まりません

PopGuardは Windows 標準のトースト通知を抑止できません。
通知を抑えたい場合は、Windows の「応答不可」や「フォーカス セッション」、設定の「システム > 通知」からアプリごとの通知を
オフにしてください。

## アイコンが灰色のままです

PopGuardは既定では抑止していません。タスクトレイのメニューから「ウィンドウを抑止する」を選ぶか、
（連動が有効な場合は）Windows のフォーカス セッションを開始すると、抑止が始まりアイコンが緑になります。

## 設定を変更したい

システム管理者へお問い合わせください。設定ファイルは管理者権限で管理されており、
利用者による変更は想定されていません。

\newpage

# 制限事項

* PopGuardが抑止できるのは、**アプリが表示する最前面のウィンドウ**だけです。
  Windows 標準のトースト通知は抑止できません。
* 対象は**同じユーザーのセッション内**のウィンドウに限られます。
  管理者権限のアプリや、他のユーザーのセッションのウィンドウは操作できません。
* モーダルダイアログは、安全のため抑止の対象外です。
* ウィンドウが出てから裏へ送られるまでに、ごく短い間だけ見えることがあります。
* Windows のフォーカス連動は、**フォーカス セッション**が対象です。手動の「応答不可」には連動しません。
